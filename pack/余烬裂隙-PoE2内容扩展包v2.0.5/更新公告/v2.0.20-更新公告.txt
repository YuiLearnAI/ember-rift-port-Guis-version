余烬裂隙 v2.0.20 更新公告
（2026-10-30 · 抱团节点：四角分布 / 先点簇节点 / 换成 inc 与 more 词条）

一、簇节点改成四角均匀分布
- 每个抱团显著节点周围固定 4 个簇节点，按 45° / 135° / 225° / 315° 四个方向均匀摆放；
- 不再使用「主属性 / 副属性」这种模糊说法。

二、顺序反过来：先点簇节点，才能点显著节点
- 簇节点各自有一条连线接回主蛛网，可以独立点亮；
- 抱团显著节点被锁住：4 个簇节点全部点亮前无法点，点它会提示「先点亮周围 4 个簇节点（x/4）」；
- 快速加点寻路也会避开未解锁的显著节点，不会卡住。
- 4 个簇节点全亮后，显著节点变为可点亮（2 点）。

三、词条改成具体的 inc / more 伤害
- 抱团显著节点固定：区域伤害提高（inc）+20%、更多伤害（more）+4%；
- 每个簇节点：对应具体词条 +7%（火焰区就是火伤、暴击率、范围、元素伤害之类），外加区域 inc +3%；
- 显著节点成长：每点亮 1 个簇节点，额外 区域 inc +6% / more +1%；4 个全亮再额外 more +2%；
- 「更多伤害」是真正的乘算（走技能 more 乘区，不是加法），inc 走原来的加算属性系统；
- 悬停显示：「抱团显著节点 x/4 · 每点亮 1 个簇节点：区域伤害 +6% / 更多伤害 +1%，全亮再 +2% 更多伤害」。

四、验证
- 语法 ALL OK；引导 280 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 7 个抱团显著节点 + 28 个簇节点（每个 4 个）；
  - 只点显著节点时被锁；4 个簇节点点满后显著节点可点亮；
  - 簇节点成长后 区域 inc 与 more 都增加，more 会实际乘进技能伤害。
