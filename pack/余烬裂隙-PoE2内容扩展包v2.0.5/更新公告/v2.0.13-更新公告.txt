余烬裂隙 v2.0.13 更新公告
（2026-10-30 · 眩晕保底只给陨石/彗星）

一句话：以前所有命中都会额外加 0.6% 眩晕保底，现在只有「陨石术 / 彗星」这类砸下来的技能才加，
其它技能按正常眩晕公式计算。

一、改动
- 眩晕保底（对稀有/首领怪，单次伤害占比很低时也能看到眩晕条增长）：
  - 旧：任意命中都会额外 +0.6%；
  - 新：只有技能 id 为 meteor（陨石术）或 comet（彗星）的命中才额外 +0.6%；
- 其它技能（火球/电弧/冰霜新星/近战/投射物等）不再吃这个保底，眩晕值完全按原本的
  「伤害占比 × 权重 × 怪物稀有度系数」公式计算；
- 同时移除了旧热修里那条「按首领掉血自动加 0.6%」的全局补丁（它不区分技能，会绕过新规则）。

二、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 陨石术命中稀有怪 → 眩晕 +0.006；
  - 彗星命中 → +0.006；
  - 火球命中 → 不加（保持 0），按正常公式走。
