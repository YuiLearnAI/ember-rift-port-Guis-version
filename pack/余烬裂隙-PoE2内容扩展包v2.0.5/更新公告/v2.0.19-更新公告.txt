余烬裂隙 v2.0.19 更新公告
（2026-10-30 · 快速出售即时刷新 / 工艺台补全高级通货）

一、快速出售后背包立即刷新
【现象】在背包点"快速出售稀有装备/无关主手武器"后，物品要关掉背包再开才消失。
【修复】出售完成后立刻重绘背包，并重新挂上快速出售按钮，不用再手动关开背包；
按钮上的可卖数量也会立即更新。

二、工艺台显示高级通货
【现象】工艺台的通货列表里看不到高级崇高石 / 高级混沌石 / 高级富豪石。
【原因】工艺台的通货按钮用的是固定列表，没有包含新增的高级通货 id。
【修复】把「高级崇高石、高级混沌石、高级富豪石」加进工艺台通货列表，位置排在本家通货之后；
点击使用、预兆、灰色不可用说明等逻辑与普通通货一致。

- 语法 ALL OK；引导 280 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 工艺台通货列表包含 mods_adv_exalt / mods_adv_regal / mods_adv_chaos；
  - 快速出售稀有装备、无关主手武器仍然正常。
