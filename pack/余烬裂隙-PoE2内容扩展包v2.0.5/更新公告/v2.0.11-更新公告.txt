余烬裂隙 v2.0.11 更新公告
（2026-10-30 · 异界高级预兆 / 特殊词缀栏取消限制）

一句话：异界高级预兆（特殊词缀）不再只认崇高/混沌/剥离/神圣 4 种通货，也不再限制稀有度——
所有基础通货都能作用于特殊词缀栏，特殊栏满了就替换一条，不会再卡「特殊词缀栏已满」。

一、改了什么
- 以前：开着「异界高级预兆」时，只有崇高石/混沌石/剥离石/神圣石能改特殊词缀；其它通货要么走普通
  效果、要么提示不生效；而且必须是稀有装备、词缀总数满了还会失败。
- 现在（开预兆时，对装备使用任意基础通货）：
  - 改造 / 增幅 / 点金 / 富豪 / 崇高 / 机会 / 瓦尔 等 → 添加一条特殊词缀；
  - 混沌 / 改造类 → 同样走特殊词缀（特殊栏满就替换一条）；
  - 剥离石（scour）/ 废除石（annul）→ 移除一条特殊词缀（没有特殊词缀时改为添加一条，保证一定生效）；
  - 神圣 → 重随现有特殊词缀的数值（没有特殊词缀时改为添加一条）；
  - 特殊词缀栏上限仍是 2 条，但满了不会报错，会替换一条；总词缀满了会替换一条普通词缀腾位置；
  - 不再限制稀有度（普通/魔法/稀有不影响）；
  - 预兆只在真正改动了特殊词缀时才消耗。
- 符文 / 精华 / 工匠石 / 遗存骨 仍走各自原有玩法（镶嵌、渎灵），这个预兆不改变它们。

二、其它
- 预兆说明同步改成了「所有通货可用；特殊栏满时替换一条」；
- 物品词缀面板里特殊词缀栏的提示保持不变（异界高级预兆）。

三、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 harness_port ALL PASS，新增断言覆盖：
  - 改造/增幅/改造/点金/富豪/机会/瓦尔 在普通物品上都能加特殊词缀；
  - 特殊栏满时第 3 条会替换而不是报错，且预兆正常消耗；
  - 剥离能移除特殊词缀。
