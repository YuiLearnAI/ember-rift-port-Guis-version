余烬裂隙 v2.0.17 更新公告
（2026-10-30 · 精华+异界高级预兆修复 / 快速出售放进背包）

一、修复：异界高级预兆 + 精华会洗掉常规词缀
【现象】开着「异界高级预兆」用精华时，精华把常规词缀栏的词条全洗了，而不是改特殊词缀栏。
【原因】精华（ess）被排除在异界高级预兆的拦截之外，走了精华原本的「重洗整件装备」逻辑。
【修复】精华现在也走异界高级预兆：只动特殊词缀栏，常规词缀原样保留；
精华仍按自己的词缀类型随机（火焰精华给火焰类词缀等），并正常消耗预兆。

二、快速出售放进背包界面
背包页顶部新增两个按钮（商人「出售」页也保留）：
- **快速出售稀有装备 (N)**：卖掉背包里所有稀有（金色）装备；
- **快速出售无关主手武器 (N)**：卖掉本职业用不到的主手武器（按职业可用武器类型判断，
  例如游侠卖掉非弓的主手武器）；传奇（暗金）装备不会被这个按钮卖掉。
两个按钮都显示当前可卖数量，卖出的物品照常进商人「回购」列表。

三、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 开预兆用精华后，常规词缀 id 完全不变、特殊词缀 +1、预兆被消耗；
  - 快速出售稀有装备能卖掉；
  - 快速出售无关武器只卖本职业用不到的，本职业能用的武器保留。
