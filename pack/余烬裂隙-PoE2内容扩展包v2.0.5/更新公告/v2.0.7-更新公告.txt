余烬裂隙 v2.0.7 更新公告
（2026-10-30 · 物品名字重复/错位显示修复）

一句话：修掉你截图里的「屏幕上物品名字错误显示」——那是 v2.0.5 加的 DOM 名字层和游戏自带的
掉落文字在筛选模式下同时绘制，两份文字大小/位置不同，看起来就像名字错了。本版已移除重复层。

一、问题
- 按 Alt / 开着物品筛选跑图时，地面掉落物的名字会出现两遍：一遍是游戏自带的（小字），
  一遍是 v2.0.5 加的 DOM 兜底名字（大字），两者位置和字号不同；
- 掉落物一多就特别明显，看起来像「名字错误」。

二、修复
- 移除 v2.0.5 添加的 DOM 掉落名字层，恢复由游戏本体的筛选文字统一绘制；
- 保留 v2.0.5 的根因修复（缺图标掉落不再中断整帧）和 F 互动提示的 DOM 兜底；
- 掉落名字不会再出现重复/错位。

三、包含之前几版修复（累计）
- v2.0.5：吞字/贴图消失（缺图标掉落导致整帧抛错）、画面突然变小/黑屏（视野自愈）；
- v2.0.6：符文师工匠石每件装备只能用一次；先符文师再普通工匠石不再被卡；背包不再误删两件相同装备；
- v2.0.7：本版，物品名字重复显示修复。

四、验证
- 语法检查 ALL OK；引导测试 279 帧 0 异常；玩法回归 harness_port ALL PASS；
- 符文师/工匠石顺序断言 ALL PASS；
- 发布版内已无 DOM 掉落名字层代码。

五、其他已知项（等确认）
- 符文之语「终焉」重复/叠加是否符合设计意图；
- 手机端：技能开孔、星图点选、剑圣流星断——需要机型+操作步骤；
- 发布检查工具误报（工具问题，不影响玩家）。
