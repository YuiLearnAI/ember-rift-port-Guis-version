余烬裂隙 v2.1.0 更新公告
（2026-10-30 · 游戏本体版本号 2.1.0）

一、版本号
- 游戏本体版本号从 2.0.x 正式提升为 **2.1.0**；
- 发布文件更名为：余烬裂隙-异界内容扩展-v2.1.0.html；
- 热修数据（hotfix.json）同步为 2.1.0。

二、本版本包含的内容（2.0.5 → 2.1.0 累计）
- 吞字 bug（技能贴图/小地图/掉落文字消失）修复；
- 画面变小/黑屏（镜头与布局自愈）修复；
- 猎首删除属性提升、咒符位词条；法血删除咒符位词条；
- 珠宝镶嵌 / 珠宝出售 / 快速出售（稀有装备、无关主手武器）修复；
- 切屏 / 静音后的环境底噪修复；
- 眩晕保底只对陨石/彗星生效；
- 时空之肌减 CD 对短 CD 技能生效（下限 0.1 秒）；
- 超越地图稀有度、符文师工匠石、背包重复物品等修复；
- 异界高级预兆：精华/高级通货联动、只改特殊词缀、T2+ 规则修复；
- 工艺台补全通货显示；
- 高级基底天赋树：抱团显著节点改为「显著节点 + 四角 4 簇节点、先点簇后点核心」；
- 遗存骨固定渎灵词缀阶级：远古 T1 / 遗存 T2 / 啃噬 T4；
- 精华只保留 2 条本精华词缀，固定 T1/T2；
- 删除高级崇高石 / 高级混沌石 / 高级富豪石（bug 过多）。

三、验证
- 语法 ALL OK；引导 279 帧 0 异常；玩法回归 ALL PASS。
