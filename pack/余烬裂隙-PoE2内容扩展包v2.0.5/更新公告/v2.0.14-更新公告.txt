余烬裂隙 v2.0.14 更新公告
（2026-10-30 · 时空之肌减 CD 对短 CD 技能生效）

一句话：时空之肌（秘法长袍）的「技能冷却 -2 ~ -1 秒」现在对冷却 <2 秒的技能也生效，
并且技能冷却最低按 0.1 秒计算，不会减成 0 或负数。

一、规则
- 装备时空之肌后，所有带冷却的技能都吃这件装备的减 CD（按件 roll 的 -2 ~ -1 秒）：
  - 冷却 3 秒 + -1 秒 → 2 秒；
  - 冷却 1.5 秒 + -1 秒 → 0.5 秒；
  - 冷却 1.5 秒 + -2 秒 → 下限 0.1 秒；
- 冷却下限统一为 0.1 秒（不再出现 0 冷却/负冷却）；
- 只对「带冷却的技能」生效，无冷却技能不受影响；
- 减 CD 数值仍按每件装备单独 roll（tooltip 显示的就是该件实际数值）。

二、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 装备时空之肌后，cdBase 1.5 → 减到 0.1~0.5；
  - cdBase 0.3 → 被限制到 0.1，不会变成 0/负数。
