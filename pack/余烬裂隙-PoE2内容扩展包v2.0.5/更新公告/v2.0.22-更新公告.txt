余烬裂隙 v2.0.22 更新公告
（2026-10-30 · 异界高级预兆对高级E / 高级C / 高级富豪石生效）

一、修复
【现象】开着「异界高级预兆」用高级崇高石 / 高级混沌石 / 高级富豪石时，预兆不生效：
要么变成普通洗装备，要么反复回滚、预兆被吃掉。
【原因】高级通货有「必定 T2」的重试逻辑：它会反复把装备恢复到快照再重洗。
但预兆效果是"改特殊词缀"，第一次成功后预兆已经被消耗；重试循环又把装备回滚，于是
后面几轮变成普通通货、或者直接失败，看起来就是"预兆不生效"。
【修复】检测到「异界高级预兆」激活时，高级通货不再走 T2 重试，直接把这一次操作交给
预兆的特殊词缀逻辑：只改特殊词缀栏、不洗常规词缀、预兆只消耗 1 次。
没开预兆时，高级通货仍然保持「必定 T2」的规则。

二、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 ALL PASS，新增断言：
  - 开预兆 + 高级崇高石：常规词缀不变、特殊词缀 +1、预兆消耗；
  - 开预兆 + 高级混沌石：特殊词缀生效、预兆只消耗一次；
  - 不开预兆的高级崇高/混沌/富豪石仍正常。
