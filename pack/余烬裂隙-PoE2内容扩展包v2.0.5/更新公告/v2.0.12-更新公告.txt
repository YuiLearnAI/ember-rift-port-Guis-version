余烬裂隙 v2.0.12 更新公告
（2026-10-30 · 异界高级预兆：按装备可用性限制通货）

一句话：修正上一版 v2.0.11 的规则——异界高级预兆只允许「这件装备按普通规则本来就能用」的通货，
不能用的通货会被正常拒绝（例如稀有装备不能用富豪石）。

一、规则
- 开「异界高级预兆」后使用通货时，先按普通规则检查这颗通货能不能用于当前装备：
  - 蜕变石/点金石/机会石/瓦尔宝珠 → 普通装备合法；
  - 增幅石/改造石/富豪石 → 魔法装备合法；
  - 崇高石/混沌石 → 稀有装备合法；
  - 剥离石/废除石 → 魔法或稀有装备、且有词缀可处理时合法；
  - 神圣石 → 有可重随词缀时合法；
  - 其它同理按普通规则判定。
- 合法 → 改为作用于特殊词缀栏（加/换/移除/重随），不再走普通效果；
- 不合法 → 直接返回普通规则原本的提示（例如「需要魔法物品」），不消耗预兆、不改装备；
- 特殊词缀栏满 2 条时仍然是替换一条，不会报「已满」；
- 符文/精华/工匠石/遗存骨仍走各自玩法。

二、验证
- 语法 ALL OK；引导 279 帧 0 异常；
- 玩法回归 harness_port ALL PASS，含：
  - 魔法/普通/稀有各自合法的通货都能加特殊词缀；
  - 稀有装备 + 富豪石 → 拒绝且不消耗预兆；
  - 普通装备 + 崇高石 → 拒绝；
  - 满 2 条特殊词缀时替换；剥离石能移除特殊词缀。
